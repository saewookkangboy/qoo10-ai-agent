# 문서 아카이브

실제 서비스 운영에 필요하지 않은 문서들을 한 곳에 모아둔 폴더입니다.

## 포함 내용

- **기획/명세**: PRD, 기능명세서, 디자인 스펙, 아키텍처 노트
- **개발 히스토리**: PHASE1/2/3 완료 보고, 데이터 파이프라인/크롤러 구현 요약
- **테스트·진단**: 테스트 관련 문서는 `tests/docs/`로 이동됨 (테스트 스크립트·결과는 `tests/` 참고)
- **통합·가이드**: Gemini/API 연동 요약, Spec-kit 스펙 문서
- **기타**: 서비스 개선 로그, 역할 업데이트 요약 등

서비스 실행·배포·에이전트 설계에 필요한 문서는 `doc/` 루트 및 `doc/agents/`에 있습니다.
