## 3. 갭 목록 (우선 정리 권장)

1. **상품 이미지**: 문서의 썸네일 0–25/상세 0–35/다양성 0–20/품질 0–20 구간을 코드에 반영하거나, 코드 기준을 문서에 “현행 구현 기준”으로 명시.
2. **상품 설명**: 설명 길이 구간(50/200/500/1000/2000자), 구조화 4단계(없음/줄바꿈/리스트/섹션) 문서와 코드 동기화.
3. **상품 가격**: 경쟁사 대비 포지셔닝, 정가 대비 할인가 일관성 — 문서에 “미구현” 표시 또는 추후 구현 시 코드 반영.
4. **상품 리뷰**: 평점/리뷰수/부정비율 구간표와 리뷰 품질(평균 길이) — 문서와 코드 중 한쪽으로 통일.
5. **상품 SEO**: 30/30/20/20 vs 25/25/25/25 — 문서 또는 코드 한쪽을 선택해 통일.
6. **상품 페이지 구조**: 필수 40점 상한 vs 코드의 15×4+선택+정밀분석 — 문서에 “확장 구현(정밀 분석 포함)” 절 추가 권장.
7. **상품 종합 보너스**: 전항목 Excellent +5, 4개 이상 +3 — 코드에 추가 검토.
8. **Shop 정보**: 레벨/팔로워/상품수 배점을 문서 40+35+25=100 체계에 맞추거나 문서를 코드 현행으로 수정.
9. **Shop 카테고리**: 카테고리 다양성·주력 집중도·분포 — 문서 유지 시 코드 확장 필요.
