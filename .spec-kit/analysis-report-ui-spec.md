# 상세페이지 분석 결과 UI 스펙 (심플·가독성·전문성)

- **버전**: 1.0
- **작성일**: 2026-01-28
- **관련 To-do**: todo_019

## 원칙

1. **심플**: 장식적 요소(블러 오브, 그라데이션 오버레이) 최소화. 카드·섹션은 단순한 테두리·배경으로 구분.
2. **가독성**: 타이포 위계 명확(제목/부제/본문), 여백 일관, 본문 줄간격·대비 확보.
3. **전문성**: 라벨·숫자·상태를 일관된 톤으로 표기. “분석 리포트”, “종합 점수”, “매출 강화 아이디어” 등 용어 통일.

## 레이아웃

- **페이지 배경**: 단일 그라데이션 또는 단색. 블러 오브는 1개 이하로 축소 또는 제거.
- **헤더**: “분석 리포트” + 부제 1줄. 검증/테마 토글은 한 줄에 정렬.
- **종합 점수**: 한 블록에 점수(큰 숫자) + 등급 라벨. “긴급 개선 개수”는 동일한 높이의 블록으로 나란히.
- **지표 카드(ScoreCard)**: 4열 그리드 유지. 카드 내부는 “제목 + 점수 + 등급 + 주요 제안 1~2줄”만.
- **탭**: “매출 강화 아이디어” / “메뉴얼 기반 체크리스트”. 탭 스타일은 언더라인 또는 배경색으로만 구분(과한 그라데이션 제거).
- **추천 카드**: 좌측 보더 + 제목 + 설명 + (선택) 실행 방법 접기/펼치기. 메타(예상 효과, 난이도, 시간)는 한 줄 또는 작은 뱃지로.
- **체크리스트**: 카테고리별 헤더(제목 + 완성도 %)만 굵게. 항목은 리스트 형태, 완료/미완료는 아이콘+색만으로 구분.
- **다운로드**: 섹션 제목 + 설명 1줄 + 버튼 3개. 카드 스타일은 상단 섹션과 동일한 톤.

## 컴포넌트별 변경 요약

| 컴포넌트 | 변경 |
|----------|------|
| AnalysisReport | 배경 블러 1개로 축소, 헤더 카드 단순화, 검증 카드 컴팩트/인라인, 점수·긴급 2열만, 탭 스타일 단순화 |
| ScoreCard | 그라데이션 제거, 원형 점수+프로그레스바+주요 제안 2개까지, 도움말 유지 |
| RecommendationCard | 좌측 보더 유지, 내부 그라데이션 제거, 메타 한 줄, 실행 방법 기본 펼침 유지 |
| ChecklistCard | 카테고리 헤더 단순화, 항목 카드 내부 그라데이션 제거, 여백 통일 |
